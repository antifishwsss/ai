# FAQ - Часто задаваемые вопросы

## Установка и настройка

### Q: Поддерживается ли Android без Root?
**A:** Нет, для работы AntifraudTester обязательно требуется Root доступ, так как необходима установка LSPosed/Xposed Framework для перехвата системных вызовов.

### Q: Работает ли на Android 14?
**A:** Да, AntifraudTester поддерживает Android 8.0 (API 26) и выше, включая Android 14. Убедитесь, что используете последнюю версию LSPosed.

### Q: Нужно ли перезагружать устройство после каждого изменения?
**A:** Нет, обычно достаточно перезапустить целевое приложение. Перезагрузка нужна только после:
- Первой установки и активации модуля в LSPosed
- Изменения Scope (списка приложений)
- Обновления AntifraudTester

### Q: Могу ли я использовать на Samsung устройствах?
**A:** Да, но с осторожностью. Samsung имеет дополнительные механизмы защиты (Knox), которые могут усложнить получение Root и работу Xposed. Рекомендуется использовать Google Pixel или другие устройства с более открытым bootloader.

### Q: Какой эмулятор лучше всего подходит?
**A:** Genymotion — наиболее стабильный вариант с встроенным Root. Nox Player также хорошо работает после активации Root в настройках.

## Использование

### Q: Не работает подмена Device ID, что делать?
**A:** Проверьте:
1. Модуль активирован в LSPosed? (Modules → AntifraudTester → включен)
2. Целевое приложение добавлено в Scope?
3. Перезапустили целевое приложение после настройки?
4. Логи LSPosed показывают, что hooks применяются?

### Q: Как проверить, что подмена работает?
**A:** 
1. Используйте тестовое приложение:
   ```kotlin
   val androidId = Settings.Secure.getString(
       contentResolver,
       Settings.Secure.ANDROID_ID
   )
   Log.d("TEST", "Android ID: $androidId")
   ```
2. Проверьте Dashboard в AntifraudTester — должны отображаться активные подмены
3. Смотрите логи:
   ```bash
   adb logcat | grep AntifraudTester
   ```

### Q: Можно ли подменять параметры для всех приложений сразу?
**A:** Да, в LSPosed Scope выберите "System Framework" — это применит hooks ко всем приложениям. Но будьте осторожны — это может повлиять на стабильность системы.

### Q: Frida vs Xposed — что лучше?
**A:** Зависит от задачи:
- **Xposed** (через LSPosed):
  - ✅ Работает постоянно
  - ✅ Не требует активного подключения
  - ✅ Влияет на все приложения в Scope
  - ❌ Требует перезагрузки для применения
  
- **Frida**:
  - ✅ Гибкие изменения "на лету"
  - ✅ Не требует перезагрузки
  - ✅ Проще отладка
  - ❌ Нужно активное подключение
  - ❌ Работает только пока скрипт запущен

### Q: Как сохранить конфигурацию для повторного использования?
**A:** Settings → Export Configuration → выберите имя файла. Файлы сохраняются в `/sdcard/AntifraudTester/configs/`.

## Безопасность и легальность

### Q: Это легально?
**A:** AntifraudTester легален для использования на **ваших собственных приложениях** или с **явного разрешения** владельца приложения для целей тестирования и QA. Использование для обхода защиты сторонних приложений без разрешения может нарушать законы и ToS.

### Q: Могу ли я использовать для обхода защиты в играх/приложениях?
**A:** **НЕТ.** Это нарушает условия использования и может быть незаконным. AntifraudTester предназначен исключительно для легального тестирования.

### Q: Детектируется ли AntifraudTester антифрод-системами?
**A:** Да, современные антифрод-системы могут детектировать:
- Наличие Xposed/LSPosed
- Frida
- Root
- Подмененные параметры

Это **ожидаемое поведение** — цель инструмента в том, чтобы помочь вам **протестировать** эти механизмы детекции.

## Troubleshooting

### Q: LSPosed показывает "Not active"
**A:**
1. Убедитесь, что Magisk установлен корректно
2. Переустановите LSPosed модуль через Magisk
3. Попробуйте Zygisk версию вместо Riru
4. Проверьте, что Magisk Hide не включен для LSPosed Manager

### Q: Приложение крашится после активации модуля
**A:**
1. Проверьте логи: `adb logcat | grep -E "AndroidRuntime|FATAL"`
2. Попробуйте отключить конкретные hooks в коде
3. Убедитесь, что версия приложения совместима
4. Создайте Issue с логами на GitHub

### Q: Frida выдает "Failed to spawn: unable to find process"
**A:**
1. Убедитесь, что frida-server запущен:
   ```bash
   adb shell "ps | grep frida"
   ```
2. Проверьте версии (должны совпадать):
   ```bash
   frida --version
   adb shell "/data/local/tmp/frida-server --version"
   ```
3. Перезапустите frida-server:
   ```bash
   adb shell "su -c 'killall frida-server'"
   adb shell "su -c '/data/local/tmp/frida-server &'"
   ```

### Q: Подмена работала, но после обновления приложения перестала
**A:** Приложение могло изменить свою защиту или способ получения параметров. Нужно:
1. Проверить логи
2. Возможно обновить hooks в XposedModule.kt
3. Использовать Frida для динамического анализа

### Q: Можно ли использовать без LSPosed, только Magisk?
**A:** Нет, LSPosed (или другой Xposed Framework) обязателен для работы Xposed модуля. Вы можете использовать только Frida скрипты, но тогда не будет UI приложения.

## Разработка

### Q: Как добавить свой hook?
**A:** См. подробное руководство в [development.md](development.md#добавление-нового-xposed-hook)

### Q: Можно ли создать плагин для AntifraudTester?
**A:** В текущей версии архитектура плагинов не реализована, но вы можете:

3. Собрать свою версию

### Q: Где хранятся настройки?
**A:** 
- Конфигурации: `/sdcard/AntifraudTester/configs/`
- SharedPreferences: `/data/data/com.antifraud.tester/shared_prefs/`
- Логи: logcat

## Производительность

### Q: Насколько сильно AntifraudTester влияет на производительность?
**A:** Влияние минимально:
- Xposed hooks: ~1-3% overhead
- Само приложение использует ~20-30MB RAM
- Не влияет на батарею, когда не активно

### Q: Можно ли использовать на слабых устройствах?
**A:** Да, минимальные требования: Android 8.0, 1GB RAM, но рекомендуется 2GB+ для комфортной работы.

## Обновления

### Q: Как обновить AntifraudTester?
**A:**
1. Скачайте новый APK из [releases](../releases/)
2. Установите поверх старой версии
3. В LSPosed модуль автоматически обновится
4. Перезагрузите устройство

### Q: Сохранятся ли мои настройки после обновления?
**A:** Да, если вы не удаляли приложение, все настройки сохранятся.
