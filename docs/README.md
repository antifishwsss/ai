## Введение

AntifraudTester — это мощный инструмент для тестирования систем защиты от мошенничества (antifraud) в Android приложениях. Он позволяет:

- **Подменять параметры устройства** — изменять идентификаторы (IMEI, Android ID, Serial) для проверки логики детекции
- **Эмулировать различные окружения** — тестировать приложение в условиях эмулятора, VPN, прокси
- **Контролировать геолокацию** — подменять GPS координаты для проверки геозащиты
- **Модифицировать сетевые параметры** — изменять IP, User-Agent, информацию об операторе
- **Отслеживать изменения** — визуальный лог всех подмен и их результатов

## Для кого этот инструмент?

- **QA инженеры** — тестирование антифрод-систем
- **Security researchers** — исследование механизмов защиты
- **Разработчики** — проверка корректности работы защиты
- **Аналитики безопасности** — аудит мобильных приложений

## Архитектура

AntifraudTester состоит из трех основных компонентов:

### 1. Android приложение (Kotlin + Compose)
- Интуитивный UI с Material Design 3
- Dashboard для мониторинга статуса
- Профили и пресеты для быстрой настройки
- Экспорт и импорт конфигураций

### 2. Xposed модуль
- Перехват системных вызовов на уровне фреймворка
- Подмена значений до того, как их увидит приложение
- Работа с любыми приложениями без их модификации

### 3. Frida скрипты
- Runtime инструментация
- Гибкая настройка через JavaScript
- Возможность изменения параметров "на лету"

## Основные возможности

### Device Info Spoofing
- IMEI / MEID
- Android ID
- Serial Number
- MAC Address
- Build информация (Model, Brand, Manufacturer)
- Hardware серийные номера

### Location Spoofing
- GPS координаты (Latitude, Longitude)
- Altitude (высота)
- Accuracy (точность)
- Интерактивная карта для выбора локации
- Сохранение часто используемых точек

### Network Spoofing
- IP Address
- Network Carrier
- User-Agent strings
- WiFi SSID/BSSID
- Proxy settings
- VPN detection bypass

### Behavioral Emulation
- Sensor data (акселерометр, гироскоп)
- Touch patterns
- Typing speed
- App usage patterns

### Templates & Profiles
- Быстрые шаблоны (Emulator, VPN, Bot)
- Пользовательские профили
- Импорт/экспорт настроек
- Batch операции

## Требования

### Минимальные требования:
- Android 8.0 (API 26) или выше
- Root доступ
- 50MB свободного места

### Рекомендуемые:
- Android 10.0 (API 29) или выше
- Magisk 24.0+
- LSPosed 1.8.0+
