# Быстрый старт

Начните работу с AntifraudTester за 5 минут.

## Предварительные условия

✅ AntifraudTester установлен ([инструкция](installation.md))  
✅ LSPosed активирован  
✅ Устройство перезагружено после настройки

## Ваш первый тест

### Сценарий: Подмена Device ID

Проверим, как приложение реагирует на измененный Android ID.

#### Шаг 1: Откройте AntifraudTester

1. Найдите иконку приложения на устройстве
2. Запустите AntifraudTester
3. Вы увидите Dashboard с статусом модулей

#### Шаг 2: Настройте подмену Device ID

1. Перейдите на вкладку **"Device"** (вторая иконка в нижнем меню)
2. Найдите пункт **"Android ID"**
3. Нажмите на него
4. В открывшемся диалоге:
   - Выберите "Custom value"
   - Введите: `test_android_id_123`
   - Нажмите "Apply"

#### Шаг 3: Проверьте подмену

Теперь нужно проверить, что подмена работает.

**Вариант А: Использование тестового приложения**

```kotlin
// В тестовом приложении запросите Android ID
val androidId = Settings.Secure.getString(
    contentResolver,
    Settings.Secure.ANDROID_ID
)
Log.d("Test", "Android ID: $androidId")
// Ожидаемый результат: "test_android_id_123"
```

**Вариант Б: Через ADB**

```bash
# Запустите целевое приложение
adb shell am start -n com.target.app/.MainActivity

# Проверьте логи
adb logcat | grep -i "android_id"
```

#### Шаг 4: Проверьте Dashboard

Вернитесь в AntifraudTester на вкладку **"Dashboard"**:
- ✅ Device Spoofing: Active
- Список активных подмен должен показывать "Android ID: test_android_id_123"

## Пример 2: Подмена местоположения

### Сценарий: Изменить GPS на Москву, Красная площадь

#### Шаг 1: Перейдите в Location

1. Откройте вкладку **"Location"** (третья иконка)
2. Вы увидите карту и текущие координаты

#### Шаг 2: Установите координаты

**Вариант А: Через карту (в будущих версиях)**
- Тап на карте установит координаты

**Вариант Б: Ручной ввод**
1. Найдите поле "Latitude"
2. Введите: `55.753215`
3. Найдите поле "Longitude"
4. Введите: `37.622504`
5. Нажмите "Enable Spoofing"

#### Шаг 3: Проверьте

```kotlin
// В тестовом приложении
val location = locationManager.getLastKnownLocation(LocationManager.GPS_PROVIDER)
Log.d("Test", "Lat: ${location?.latitude}, Lon: ${location?.longitude}")
// Ожидаемый результат: Lat: 55.753215, Lon: 37.622504
```

## Пример 3: Использование готовых профилей

### Сценарий: Эмуляция типичного эмулятора

#### Шаг 1: Откройте Settings

1. Перейдите на вкладку **"Settings"**
2. Найдите секцию "Profiles"

#### Шаг 2: Выберите профиль

1. Выберите предустановленный профиль **"Generic Emulator"**
2. Нажмите "Apply"

Этот профиль автоматически установит:
- Build.MANUFACTURER = "Genymotion"
- Build.MODEL = "Generic Android"
- Build.BRAND = "generic"
- Серийный номер эмулятора
- MAC адрес эмулятора

#### Шаг 3: Проверьте антифрод

Запустите целевое приложение и посмотрите:
- Обнаруживает ли оно эмулятор?
- Какие признаки эмулятора проверяются?
- Блокируется ли функционал?

## Пример 4: Экспорт конфигурации

### Сценарий: Сохранить настройки для повторного использования

#### Шаг 1: Создайте конфигурацию

1. Настройте нужные параметры (Device ID, Location и т.д.)
2. Перейдите в **Settings**
3. Найдите "Export Configuration"

#### Шаг 2: Экспортируйте

1. Нажмите "Export Configuration"
2. Введите имя: `my_test_config`
3. Файл сохранится в `/sdcard/AntifraudTester/configs/`

#### Шаг 3: Импортируйте позже

1. Settings → Import Configuration
2. Выберите файл `my_test_config.json`
3. Все настройки применятся автоматически

## Использование Frida скриптов

### Сценарий: Подмена IMEI через Frida

Если вы предпочитаете более гибкий подход или нужна подмена для конкретного приложения:

#### Шаг 1: Запустите frida-server

```bash
# На устройстве (через adb shell)
su
/data/local/tmp/frida-server &
```

#### Шаг 2: Запустите скрипт

```bash
# На хост-машине
cd /path/to/ai/frida

# Вариант А: При запуске приложения
frida -U -f com.target.app -l device_spoof.js --no-pause

# Вариант Б: К уже запущенному приложению
frida -U com.target.app -l device_spoof.js
```

#### Шаг 3: Проверьте логи

В консоли Frida вы увидите:
```
[*] AntifraudTester: Device ID Spoofing активирован
[*] Hooking Android ID...
[+] Android ID перехвачен!
[*] Hooking IMEI...
[+] IMEI (getDeviceId) перехвачен!
```

#### Шаг 4: Изменяйте параметры на лету

Некоторые скрипты поддерживают RPC:

```python
import frida
import sys

device = frida.get_usb_device()
session = device.attach("com.target.app")

with open("location_spoof.js") as f:
    script = session.create_script(f.read())
    script.load()

# Изменить координаты
script.exports.set_location(40.7128, -74.0060, 10)  # Нью-Йорк

print("Координаты изменены. Нажмите Enter для выхода...")
sys.stdin.read()
```

## Комбинированный подход

Для максимальной эффективности используйте оба метода:

1. **Xposed (через LSPosed)** — для постоянной подмены на уровне системы
   - Работает всегда
   - Не требует перезапуска
   - Влияет на все приложения в Scope

2. **Frida** — для точечных изменений и экспериментов
   - Гибкость
   - Изменение на лету
   - Для конкретного приложения

## Типичные сценарии тестирования

### ✅ Проверка детекции эмулятора
1. Примените профиль "Generic Emulator"
2. Запустите приложение
3. Проверьте, детектируется ли эмулятор

### ✅ Проверка геоблокировки
1. Установите Location в запрещенной стране
2. Проверьте, блокируется ли доступ
3. Попробуйте разные страны

### ✅ Проверка антифрод на уникальность устройства
1. Клонируйте все параметры с другого устройства
2. Запустите приложение на обоих
3. Проверьте, детектируется ли дубликат

### ✅ Стресс-тест генерации токенов
1. Быстро меняйте Device ID
2. Запрашивайте новые токены
3. Проверьте, есть ли rate limiting
