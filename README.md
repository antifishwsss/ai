# AntifraudTester

**AntifraudTester** — стильное универсальное Android-приложение для тестирования антифрод-систем.

## Возможности

**AntifraudTester** позволяет:
- Подменять ключевые параметры устройства (Device ID, IMEI, GPS, сеть, сенсоры и др.)
- Мгновенно запускать тестовые сценарии через удобное интуитивное меню с профилями и пресетами
- Быстро видеть, что реально подменено и на какие значения благодаря наглядному Dashboard
- Проверять логику защиты и сразу видеть результат, экспортировать отчеты

## Модули

### Модули включают:
- **Подмену Device Info** — IMEI, Android ID, Serial, MAC и другие идентификаторы устройства
- **Location spoofing** — подмена местоположения с интерактивной картой
- **Сетевые параметры** — подмена IP, Carrier, User-Agent
- **Поведенческая эмуляция** — эмуляция сенсоров, тапов, ускорения
- **Быстрые шаблоны** — готовые профили (эмулятор, VPN, бот-профиль)
- **Логер проверок** — визуальный diff-лог всех изменений

## Простая установка (root)

### Требования
- Android устройство или эмулятор с Root доступом
- Поддерживаются: Genymotion, Nox, Pixel/Real device с Magisk

### Шаги установки

1. **Установите эмулятор или устройство с Root**  
   Поддерживаются: Genymotion, Nox, Pixel/Real device c Magisk.

2. **Установите Magisk + LSPosed**  
   Инструкции: https://github.com/LSPosed/LSPosed

3. **Скачайте APK из releases**  
   В каталоге проекта `./releases/latest.apk` (или GitHub Releases).

4. **Установите APK:**
   ```sh
   adb install ./releases/latest.apk
   ```
   или перенесите файл вручную и установите как обычное приложение.

5. **Активируйте модуль в LSPosed**  
   Откройте LSPosed Manager и добавьте AntifraudTester в scope.

6. **Запустите приложение**  
   Dashboard-интерфейс вам сразу покажет статус и позволит быстро начать подмену.
